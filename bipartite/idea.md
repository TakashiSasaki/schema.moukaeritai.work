一般に語のセットを表現することを考える。
JSONのプロパティは重複を許さない文字列の集合と考えられるので、
```
{
    "term_1" : null,
    "term_2" : null,
    "term_3" : null
}
```

のようにして term1, term2, term3 という3つの単語の集合を表現することができる。

----

次に、その語と別の語の関係を二部グラフで書くことを考える。

```
{
    "term_1" : [ "term_a" ],
    "term_2" : [ "term_b", "term_c", "term_d" ],
    "term_3" : [ "term_e", "term_f" ]
}
```

各プロパティの値は文字列の配列とする。
配列の順序を無視すればこれは二部グラフを表していると言える。
