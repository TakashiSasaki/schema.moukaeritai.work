## Commit Process

### Decision (2025-12-05)

**Decision:** When committing changes, use a temporary file for the commit message with `git commit -F` as requested by the user.

**Reason:** The user specifically requested this method for commit messages. This allows for easier editing and potentially more structured messages.

**Guideline:** Create detailed commit messages when committing.
