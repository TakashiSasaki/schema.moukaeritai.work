EFU (Everything File List) Schema

Everything Search Engine が出力する EFU (Everything File List) 形式（ヘッダ付き CSV）を CSVW (CSV on the Web) / JSON-LD として記述するためのスキーマ定義です。

識別子（概念 URI）

このスキーマの概念的な識別子（Namespace / Base URI）は以下です：
https://schema.moukaeritai.work/efu/
