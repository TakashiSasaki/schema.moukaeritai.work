EFU CSVW Schema v0.1

Everything の EFU（CSV ファイル一覧）を CSVW / JSON-LD として記述するスキーマ定義（v0.1 / draft）。

識別子（概念 URI）

このページ（https://schema.moukaeritai.work/efu/0.1）は、 スキーマ資源そのもの（記述対象）の概念 URI です。 具体表現（JSON / Turtle / RDF/XML）は下記リンクから取得できます。

ダウンロード（具体表現）

スキーマ本体

  • schema.json (application/ld+json または application/json)
  • schema.ttl (text/turtle)
  • schema.rdf (application/rdf+xml)

JSON-LD Context（辞書）

  • context/base.jsonld (application/ld+json)

注: context は JSON-LD 処理系が @context から実際に取得する可能性があるため、 URL で取得可能な資源として公開します。

メタデータ

  • Version: 0.1 (draft)
  • Release date: 2025-12-19
  • Creator: Takashi Sasaki (https://x.com/TakashiSasaki)

取得例（CLI）

サーバが Content Negotiation（Accept による表現切替）を提供している場合の例です。 静的ホスティングで conneg を提供しない場合でも、上の直接リンクで取得できます。

JSON(-LD)

curl -H "Accept: application/ld+json" https://schema.moukaeritai.work/efu/0.1

Turtle

curl -H "Accept: text/turtle" https://schema.moukaeritai.work/efu/0.1

RDF/XML

curl -H "Accept: application/rdf+xml" https://schema.moukaeritai.work/efu/0.1

Direct

curl https://schema.moukaeritai.work/efu/0.1/schema.json
curl https://schema.moukaeritai.work/efu/0.1/schema.ttl
curl https://schema.moukaeritai.work/efu/0.1/schema.rdf

関連

  • Latest (alias): /efu/latest.json (可変)
  • CSVW Namespace: https://www.w3.org/ns/csvw

このページは人間可読の案内ページです。スキーマの同一性は概念 URI（本ページ URL）で表し、 具体表現は schema.json / schema.ttl / schema.rdf として提供します。
