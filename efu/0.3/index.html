EFU CSVW Schema v0.3

Everything の EFU（CSV ファイル一覧）を CSVW / JSON-LD として記述するスキーマ定義（v0.3 / draft）。
v0.2 の定義に加え、観測情報（メタデータ）を記録するためのオプショナルカラム Seen Date, Seen Host, Seen User を含みます。

識別子（概念 URI）

このページ（https://schema.moukaeritai.work/efu/0.3）は、 スキーマ資源そのもの（記述対象）の概念 URI です。 具体表現（JSON / Turtle / RDF/XML）は下記リンクから取得できます。

ダウンロード（具体表現）

スキーマ本体

  • schema.jsonld (application/ld+json または application/json)
  • schema.ttl (text/turtle)
  • schema.rdf (application/rdf+xml)

メタデータ

  • Version: 0.3 (draft)
  • Release date: 2025-12-19
  • Creator: Takashi Sasaki (https://x.com/TakashiSasaki)

取得例（CLI）

サーバが Content Negotiation（Accept による表現切替）を提供している場合の例です。

JSON(-LD)

curl -H "Accept: application/ld+json" https://schema.moukaeritai.work/efu/0.3

Turtle

curl -H "Accept: text/turtle" https://schema.moukaeritai.work/efu/0.3

RDF/XML

curl -H "Accept: application/rdf+xml" https://schema.moukaeritai.work/efu/0.3

Direct

curl https://schema.moukaeritai.work/efu/0.3/schema.jsonld
curl https://schema.moukaeritai.work/efu/0.3/schema.ttl
curl https://schema.moukaeritai.work/efu/0.3/schema.rdf

関連

  • Previous version: v0.2
  • Latest (alias): /efu/latest.json (可変)
  • CSVW Namespace: https://www.w3.org/ns/csvw
