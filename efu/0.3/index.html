EFU CSVW Schema v0.3

Everything の EFU（CSV ファイル一覧）を CSVW / JSON-LD として記述するスキーマ定義（v0.3 / draft）。

Schema URI: https://schema.moukaeritai.work/efu/0.3

v0.2 の定義に加え、観測情報（Seen Date等）やコンテンツハッシュ（MD5, SHA-1, SHA-256, Git Blob SHA）を記録するためのオプショナルカラムを含みます。

識別子（概念 URI）

このページ（https://schema.moukaeritai.work/efu/0.3）は、 スキーマ資源そのもの（記述対象）の概念 URI です。 上部タブから各形式（JSON-LD / Turtle / RDF/XML）の定義を直接閲覧できます。

取得例（CLI）

サーバが Content Negotiation（Accept による表現切替）を提供している場合の例です。

JSON(-LD)

curl -H "Accept: application/ld+json" https://schema.moukaeritai.work/efu/0.3

Turtle

curl -H "Accept: text/turtle" https://schema.moukaeritai.work/efu/0.3

RDF/XML

curl -H "Accept: application/rdf+xml" https://schema.moukaeritai.work/efu/0.3
